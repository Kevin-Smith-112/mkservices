# MK Services

A marketing site for a fictional Kelowna-area property services business — window
cleaning, gutter cleaning, yard clean-up, Christmas light installation, Halloween
decorating, and handyman work. Built with plain HTML/CSS/JS — no framework or build step.

## Contents

- `index.html` — hero, service cards (with photos), seasonal booking callout, service
  area map, and a quote-request form
- `styles.css` — responsive, mobile-first styling
- `script.js` — mobile nav toggle, back-to-top button, and a client-side form handler
  (no backend wired up — the form shows a confirmation message only)
- `images/` — service photos (sourced from [Pexels](https://www.pexels.com), free to use
  under the Pexels License)

## Local preview

Open `index.html` directly in a browser, or serve the directory with any static file
server, e.g.:

```bash
python3 -m http.server 8000
```
